# KidZoo — Graduation Project

Kids educational/gaming app with **Visual Perception Disorder** detection via a machine-learning model (Logistic Regression trained on game-trial metrics).

## Project Structure

```
kidzoo app/
├── backend/              # Laravel 12 REST API (Flutter-facing)
│   ├── API_DOCUMENTATION.md     # Full endpoint reference for the Flutter dev
│   └── ...
├── ml_service/           # Python FastAPI microservice
│   ├── data/visual_perception_dataset.csv
│   ├── artifacts/               # model + scaler + metadata (generated by train.py)
│   ├── train.py                 # trains LogisticRegression
│   ├── api.py                   # /predict and /plan endpoints
│   └── README.md
└── README.md
```

## Services

| Service | Port | Purpose |
|---|---|---|
| Laravel API | 8000 | Auth, children, games, sessions, dashboard, notifications |
| FastAPI ML | 8001 | Optional external classifier for richer ML predictions |

Flutter talks only to **Laravel**.
Laravel can either:
- use the built-in local rule-based prediction flow, or
- proxy prediction requests to the optional FastAPI ML service.

## Start Locally

**Backend only (recommended for quick setup):**
```bash
cd backend
php artisan serve --host=127.0.0.1 --port=8000
```

**Optional ML service:**
```bash
cd ml_service
./venv/Scripts/python.exe -m uvicorn api:app --host 127.0.0.1 --port 8001
```

**Laravel with external ML enabled:**
```bash
cd backend
php artisan serve --host=127.0.0.1 --port=8000
```

## First-time Setup

```bash
# ML service
cd ml_service
python -m venv venv
./venv/Scripts/python.exe -m pip install -r requirements.txt
./venv/Scripts/python.exe train.py          # produces artifacts/

# Laravel
cd ../backend
composer install
cp .env.example .env                         # default is ML_SERVICE_MODE=local
php artisan key:generate
php artisan migrate:fresh --seed --force
```

## Model Performance

Trained on `visual_perception_dataset.csv` (300 rows, 30 users, 4 task types):
- **Accuracy:** 91.1%
- **F1 (Visual_Perception_Disorder):** 0.83
- Algorithm: LogisticRegression (`C=0.25`, `l2`, `max_iter=1000`)
- Features: raw trial metrics + one-hot categoricals (Task_Type, Difficulty_Level, Target_Type), 70% feature subset (seed=42)
